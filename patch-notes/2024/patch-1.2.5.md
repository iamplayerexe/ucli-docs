# Patch 1.2.5

## **Voici toutes les nouveautés de la version 1.2.5 !**

* <mark style="color:green;">Ajouts</mark>:
  * Commande _<mark style="color:purple;">**/avatar**</mark>_:
    * Permet d'afficher l'avatar de l'utilisateur.
  * Commande _<mark style="color:purple;">**/userinfo**</mark>_:
    * Permet d'afficher les informations de l'utilisateur.

{% hint style="info" %}
Toute permission `ADMINISTRATEUR` obtient des informations supplémentaires sur l'utilisateur.
{% endhint %}

* <mark style="color:orange;">Modifications</mark>:&#x20;
  * Fonctionnalité _<mark style="color:purple;">**maintenance**</mark>_:
    * Correction d'un bug qui empêchait d'annoncer la durée de la maintenance.
    * Modification de la syntaxe de certaines phrases.
  * Commande _<mark style="color:purple;">**/bot**</mark>_:
    * Modification de l'affichage du message. (Seulement disponible sur PC)
  * Fonctionnalité _<mark style="color:purple;">**ready**</mark>_:
    * Le <mark style="color:yellow;">Uptime</mark> sur le message est maintenant modifié lorsque <img src="../../.gitbook/assets/ucli-logo.png" alt="" data-size="line"><mark style="color:red;">uCLI</mark>  est hors ligne.

{% hint style="info" %}
_<mark style="color:purple;">**Ready**</mark>_ est une fonctionnalité qui permet d'annoncer la mise en ligne de<img src="../../.gitbook/assets/ucli-logo.png" alt="" data-size="line"><mark style="color:red;">uCLI</mark> lors de son démarrage.
{% endhint %}



***

{% hint style="info" %}
Dans la version <mark style="color:orange;">1.2.5</mark>, <img src="../../.gitbook/assets/ucli-logo.png" alt="" data-size="line"><mark style="color:red;">uCLI</mark> n'est pas publique.&#x20;
{% endhint %}
