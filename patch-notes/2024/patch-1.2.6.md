# Patch 1.2.6

## **Voici tout ce que vous devez savoir de la version **<mark style="color:orange;">**1.2.6**</mark>** !**



* <mark style="color:green;">**Ajouts**</mark>**:**
  * Commande _<mark style="color:purple;">**/announce**</mark>_:
    * Commande `DevOnly`  permettant de faire des annonces.
  * Commande _<mark style="color:purple;">**/lookup**</mark>_:
    * Commande de modération permettant de récupérer les informations de l'utilisateur.

{% hint style="info" %}
La commande _<mark style="color:purple;">**/lookup**</mark>_ nécessite la permission `ModerateMembers`.
{% endhint %}

* <mark style="color:orange;">**Modifications**</mark>**:**
  * Commande _<mark style="color:purple;">**/userinfo**</mark>_:
    * La commande _<mark style="color:purple;">**/userinfo**</mark>_ n'affiche plus d'informations supplémentaires pour toute permission.&#x20;
* <mark style="color:yellow;">**Fixs**</mark>**:**
  * Fonctionnalité _<mark style="color:purple;">**hors-ligne**</mark>_:
    * Bug qui autorisait la fonctionnalité hors-ligne à avoir des exceptions, désormais la fonctionnalité sera exécutée sur le message précédent lors du lancement de uCLI.



***



{% hint style="info" %}
Dans la version <mark style="color:orange;">1.2.6</mark>, <img src="../../.gitbook/assets/ucli-logo.png" alt="" data-size="line"><mark style="color:red;">uCLI</mark> n'est pas publique.&#x20;
{% endhint %}
